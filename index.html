🎙️ Speaker Notes (Slide 1)

When the chatbot generates an answer from European environmental documents, RAG Facts Check audits every claim in real time:

  1. Ingest: Ingests the LLM answer alongside matched source documents.
  2. Extract: Decomposes the answer into atomic claims.
  3. Judge: Crossmatches each claim against referenced documents using an LLM judge.
  4. Report: Produces grounded verification verdicts, direct evidence citations, and hallucination flags.

🎙️ Speaker Notes (Slide 2)

The fact-checking engine provides automated verification for enterprise RAG:

  • Claim Extraction: Extracts atomic factual claims from generated chatbot answers.
  • Source Grounding: Checks each claim against referenced source documents using an LLM judge.
  • Verbatim Evidence: Locates verbatim evidence spans and character offsets in the source text.
  • Hallucination Detection: Accurately detects hallucinations by flagging statements that lack document grounding (Not Enough Info).
  • Quality Score: Produces a calibrated quality score reflecting overall answer trustworthiness.
